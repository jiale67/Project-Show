# 任佳乐 · 项目展示

双击本目录的 **项目展示.html**，建议使用 Chrome 或 Edge。全部图片、视频、样式和简历都在本目录中，无需联网。

## 浏览与演示

- 点击“按当前顺序演示”，连续展示四个项目，每个项目 4 页，共 16 页。
- 点击项目卡片的“查看项目”，从该项目开始；“独立打开”可单独浏览子 HTML。
- 默认顺序：M20 巡检规划 → 机器人自主充电 → DR02 楼梯高度图 → Go2 强化学习导航。
- 使用 ← / →、PageUp / PageDown 翻页，或通过底部下拉菜单跳页。子展示也支持 Home / End。
- F：全屏；N：讲解提示；S：演讲者窗口；O：当前项目页总览。Esc 关闭提示或返回总览。
- 视频需点击播放，切换页面时自动暂停。视频控件支持单独全屏。
- 讲解提示默认隐藏。演讲者窗口适合双屏展示，请把窗口放在自己的屏幕上。
- 手机浏览子展示时，建议横屏，便于查看框架图和视频。

## 调整项目顺序

在总览点击“调整展示顺序”，拖动卡片或使用 ↑ / ↓，再点击“完成”。调整会保存在当前浏览器。

如需将排序带到另一台电脑，点击“导出排序文件”，将下载的 **展示顺序.js** 替换本目录同名文件。也可直接编辑该文件中的数组：

```js
window.PROJECT_ORDER = ["m20", "charge", "terrain", "go2"];
```

其中 m20 是巡检规划，charge 是自主充电，terrain 是楼梯高度图，go2 是强化学习导航。更改默认配置后，浏览器会采用新的顺序。

## 分享与修改

发送压缩包，或保留整个“项目展示”文件夹及其目录结构。只发送一个 HTML 会缺少配套视频和样式。收件人应先解压，再打开 **项目展示.html**。

四个子展示分别位于各项目子目录的 **index.html**；可直接用文本编辑器修改正文和 `<aside class="notes">` 内的讲解提示。公共视觉样式在 **assets/project.css** 与 **assets/engineering.css** 中。调整页数或标题时，需要同步更新 **assets/projects.js** 的页名和页数。

“制作记录”保留生成脚本、素材清单和浏览器验收结果，交付压缩包不包含该目录。

## 展示结构

每个项目依次介绍项目目标与个人工作、整体框架、核心思路、运行演示。M20 的四段现场视频集中在演示页；Go2 使用 MuJoCo 仿真素材。
